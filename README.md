# TacitOS — Voice-to-Expertise Intelligence

> Capture what experts know but never wrote down.

TacitOS is a real-time voice knowledge-capture and decision-support system built for the AssemblyAI Voice Agent Hackathon. It turns natural expert conversations into structured, traceable operational knowledge, detects conflicts and gaps, and lets the next worker query that knowledge by voice.

## Core loop

**Expert voice → AssemblyAI Voice Agent → structured tool calls → knowledge engine → conflict/gap analysis → targeted follow-up → verified guidance with provenance**

## Status

🚧 Active hackathon build.

The first milestone includes:
- Real-time browser voice agent
- Expert Capture and Apprentice Guidance modes
- Structured rule capture with source provenance
- Contradiction detection
- Knowledge coverage / gap analysis
- Explainable rule matching
- Evaluation scenarios and CI
